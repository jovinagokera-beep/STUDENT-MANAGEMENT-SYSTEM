Project Description
The Student Management System is a simple web-based application developed using PHP and MySQL. The system allows users to register student information through a two-step registration process. The first page collects login credentials, while the second page collects detailed student information before saving the data into a database.
Objectives
To register students electronically.
To store student records in a MySQL database.
To demonstrate the use of PHP and MySQL connectivity.
To simplify student information management.

System Features
1. Login Information Page
The first page allows users to enter:
 Username
Password
After entering the information, the user clicks the NEXT button to proceed to the registration page.

2. Student Details Page
The second page collects:
 Full Name
Gender
Age
Course
Email Address
Phone Number
After completing the form, the user clicks the REGISTER button.

3. Database Storage
The system stores all student information in the MySQL database automatically after successful registration.
4. Success Notification
When registration is completed successfully, a confirmation message is displayed.
